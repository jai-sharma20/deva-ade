# Welcome to DevA (Development Assitance).

Deva is the open-source Cursor alternative.

Use AI agents on your codebase, checkpoint and visualize changes, and bring any model or host locally. Deva sends messages directly to providers without retaining your data.

This repo contains the full sourcecode for Deva. If you're new, welcome!

## Contributing

1. To get started working on Deva, check out our Project Board! You can also see [HOW_TO_CONTRIBUTE](https://github.com/Devaeditor/Deva/blob/main/HOW_TO_CONTRIBUTE.md).

2. Feel free to attend a casual weekly meeting in our Discord channel!


## Reference

Deva is a fork of the [vscode](https://github.com/microsoft/vscode) repository. For a guide to the codebase, see [VOID_CODEBASE_GUIDE](https://github.com/Devaeditor/Deva/blob/main/VOID_CODEBASE_GUIDE.md).
